# Этот код — это графическое приложение на Python для планирования тренировок. Оно позволяет пользователю добавлять записи о тренировках с датой, типом и длительностью, сохранять их в JSON-файл, а также фильтровать по дате и типу тренировки. Это помогает удобно вести учет тренировочного процесса и быстро находить нужные записи.
